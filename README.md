Course Management System

Full Stack Course Management System using React.js and Spring Boot.

Features

* Login Page
* Dashboard
* Add Course
* Update Course
* Delete Course
* Add Student
* Update Student
* Delete Student
* Search Functionality

---

 Tech Stack

 Frontend

* React.js
* Axios
* React Router DOM
* CSS

 Backend

* Spring Boot
* Spring Data JPA
* Hibernate

 Database

* MySQL / Oracle SQL


Installation

 Frontend


npm install
npm run dev

Backend

Run Spring Boot Application
